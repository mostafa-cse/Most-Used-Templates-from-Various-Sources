## 🚀 How to Use

1. **Browse by topic** — navigate to the relevant folder for the algorithm or data structure you need.
2. **Copy the template** — each `.cpp` file is a self-contained, ready-to-use template.
3. **Adapt to your problem** — adjust types, sizes, or parameters as needed for your specific problem constraints.
4. **VS Code snippets** — import the `.code-snippets` files from the `My Cp Snippet` folder into VS Code for quick access to starter templates.
